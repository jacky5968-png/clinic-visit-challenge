# 藥師與掛號人員互動驗收
日期：2026-10-25；外勤養成V5；本機更新，未發布。

## 人物與操作

| 人物 | 位置與外觀 | 互動 |
| --- | --- | --- |
| 藥師 | 藥局領藥檯後方，白袍、眼鏡與綠色識別證 | 走近藥局後按E／Enter，或按「與藥師對話」 |
| 掛號人員 | 掛號櫃台後方右側，藍色制服與識別證 | 走近掛號櫃台後按E／Enter，或按「與掛號人員對話」 |

可以直接點選3D人物，自動沿安全路線走近櫃台並開啟對話。人物的碰撞範圍會阻擋穿越身體；掛號人員已避開原本通往診間的路線。地點標籤會避開人物臉部及點擊位置。

三間診所均加入兩位人員。首頁與簡易場景同步增加對應人物；沿用微軟正黑體與既有清楚配色。


```powershell

node scripts/verify-clinic-staff-preservation.mjs
node scripts/verify-readability.mjs
```
