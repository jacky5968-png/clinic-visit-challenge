## 操作與播放行為

- 右上角原音效按鈕改為「音樂與音效設定」，維持原入口位置；面板僅於開啟時浮出。
- 背景音樂與遊戲音效各有開關及0～100%音量，預設分別25%、40%。
- 讀取到舊 `clinic-sound=false` 時保留靜音偏好；可在面板重新開啟。
- 使用獨立 `clinic-audio-settings-v1` 儲存設定，不寫入或刪除原合格紀錄。
- 只有按「開始遊戲」或實際開始關卡的使用者手勢，才啟動音訊；重新整理後仍須再按開始，不會自行發聲。
- 主題曲只有一個HTML音樂播放器；音效共用一個AudioContext，解碼後重用，並限制同時音效數量。
- 交流時背景音量降至使用者設定的55%，答題時降至42%。每次答對／答錯不重新開始音樂。
- 成功結果將音樂淡出，播放3.8秒勝利音效後恢復目前音量；離開結果頁會取消尚未播放的勝利音效。音效關閉時，不刻意留下勝利音效的空白等待。
- 隱藏分頁時暫停音樂、清除當下音效及腳步，返回時依設定恢復；若瀏覽器阻擋播放，可按面板「重試播放」。
- 音檔失敗、AudioContext不可用、localStorage被封鎖時，遊戲繼續運作；元件卸載會停止計時器、取消載入、釋放音訊節點及播放器。

## 本機開啟

原「啟動遊戲.cmd」維持不變。亦可執行：

```powershell
npm run dev -- --port 5173
```

正式建置預覽：

```powershell
npm run build
npm run preview -- --port 4175 --strictPort
```

開啟 http://127.0.0.1:4175/ ，右上角設定音量，再按「開始遊戲」。以上皆為僅本機的網址，不是網站發布。
