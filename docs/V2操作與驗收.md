# 外勤養成V2｜操作與驗收

日期：2026-10-24。版本2.0.0，沿用本機專案`clinic-visit-challenge`與網址`http://127.0.0.1:5173/`。

本次依使用者選擇升級行走動畫與診所互動。產品照片停止補充，保留前次照片與待補畫面；不發布、不修改正式題庫、Google Sheets或其他專案。

## 操作

1. 選擇產品並開始拜訪。
2. 可點擊場景或小地圖的「掛號櫃檯」「候診區」「醫師診間」。櫃檯與候診區為選擇性互動，可以直接前往診間。
3. 外勤會從目前位置沿連續路線走到目的地，轉彎時改變朝向。移動中其他地點暫停操作，避免重複建立路線；可按「略過移動」。
4. 抵達櫃檯後顯示櫃檯對話；抵達候診區後顯示提醒。對話卡可關閉，再次點擊目前地點可重開。
5. 抵達診間後，任務卡切換為「進入醫師診間」。點擊「進入診間」進行原有醫師對話與五題挑戰。
6. 探索進度只存在本局。重新開始拜訪會回到入口，清除地點勾選；不保存個人成績。

首頁、頁籤標題、介面版本與成功結果皆顯示「外勤養成V2」。本地操作示範題僅同步遊戲版本文字，正式CSV內容未改動。

## 行走與互動實作

- 角色使用本專案原創SVG分層構造，手臂、髖部、膝部、身體與提包分別動畫；步態左右交替，不以額外腿部覆蓋靜態人物。
- 移動採Web Animations API與Transform，以各段距離分配時間，保持連續速度。路線從目前地點起算，不會在第二段探索時跳回入口。
- 四個可到達地點透過入口門檻、中央走道、側邊走道節點相連。不加入自由控制、完整3D或碰撞引擎。
- 背景、人物、路徑及熱點使用同一座標空間，百分比位移隨視窗大小縮放；小地圖位置點使用同一條路線同步移動。
- 任務卡、小地圖目前位置、到達對話與已探索標記會連動。地點事件不新增產品知識或臨床敘述。
- 小地圖在桌機置於場景右側，手機移至場景下方，避免遮住可點擊地點；地點按鈕可透過鍵盤操作。
- 保留略過移動與`prefers-reduced-motion`支援；減少動態效果時快速抵達，仍可完整探索與答題。
- 卸載場景、略過或變更減少動態效果設定時，取消舊動畫與回呼，避免過期動畫覆蓋新狀態。

截圖位於`output/playwright/`：`v2-reception-*`、`v2-doctor-arrival-*`與`v2-walking-*`。已檢查行走姿勢及桌機／手機場景，保留有限動畫下的實際行走擷取。

Playwright最新單次報告會反映最近執行的測試集合；完整34項結果與最後6項定向驗證分別執行。單元測試最後一次因Windows隔離環境無法清理測試快取而未啟動，改在主機執行相同命令後39項全數通過，沒有略過失敗案例。
