# 3D人物旁對話氣泡驗收

日期：2026-10-25。僅更新本機版，未發布。預覽：http://127.0.0.1:4173/。

## 呈現與操作

- 藥師／掛號人員的寒暄已移到 3D 場景內，以實色說話氣泡顯示。
- 點「回應」後，氣泡連到外勤，顯示外勤回覆；點「繼續聊聊」接續下一組問候。
- 氣泡會跟隨說話者及鏡頭位置，支援旋轉、縮放、俯視、重設及視窗尺寸變更。
- 以四位人物的實際完整模型範圍避讓，包含外勤、醫師、藥師及掛號人員的招手手臂。地點按鈕會重新排開，避免與氣泡重疊。
- 手機／平板對話時保留較高的場景空間，展開「拜訪提醒」時另增加空間。關閉後回到原場景高度。
- 中文字型沿用微軟正黑體，對話內文 18px，主要氣泡按鈕可點範圍至少 44px。
- 原本的拜訪提醒可展開查看；方向鍵行走、E／Enter 互動、醫師挑戰及簡易場景備援保留。
