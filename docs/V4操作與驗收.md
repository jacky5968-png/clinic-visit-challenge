# 外勤養成V4｜操作與驗收

日期：2026-10-25。版本4.0.0，沿用`clinic-visit-challenge`與本機網址`http://127.0.0.1:5173/`。

V4新增方向鍵自由行走、地面碰撞及靠近後互動，保留V3的3D場景、鏡頭控制、地點導航、正式CSV與五題挑戰。未發布、未補照片、未修改原題庫；升級前已建立V3備份。

## 遊玩方式

1. 選擇實際產品，按「開始拜訪」。3D載入完成後，方向鍵會控制外勤；若焦點已移到其他按鈕，先點3D場景再操作。
2. 使用方向鍵或WASD行走，按住持續前進，放開即停。方向隨目前鏡頭旋轉；斜走速度與直走一致，相反方向鍵互相抵消。
3. 手機可長按場景下方四個方向按鈕。滑出按鈕、取消手勢、放開或切換視窗會停止。按鈕也支援鍵盤焦點後長按Enter／空白鍵。
4. 走近掛號櫃檯或候診區，出現「附近」提示後，按E、Enter或互動按鈕查看對話。只靠近不會自動開啟對話；離開範圍會關閉提示及對話。
5. 走到醫師診桌前方的互動範圍，按E、Enter或「與醫師對話」，進入原有醫師對話。按兩次「繼續對話」，再按「接受醫師挑戰」。
6. 每局五題、每題20分、全對100分才通關。答案送出鎖定、正解、錯題回顧、重玩與更換產品皆沿用既有流程。

也能點選3D物件、地點標籤或小地圖自動前往；手動行走後，導航從當前位置起算，並繞過家具與隔間。導航期間可「略過移動」，方向鍵或長按方向按鈕可立即中斷導航，不會在舊計時器到期後跳回舊終點。抵達醫師後仍可按「進入診間」。

拖曳旋轉鏡頭、滾輪／雙指縮放、俯視、重設及65%～225%縮放限制保留。V4將畫布的方向鍵改為行走；鍵盤旋轉改用Alt＋方向鍵。`+`／`-`縮放，Home重設鏡頭，不會重設人物位置。

## 碰撞與互動範圍

- 人物以半徑0.24公尺的地面佔位處理，速度2.35公尺／秒。每幀限制時間步長並拆成小步，避免延遲幀直接穿過薄牆。
- 櫃檯、診桌、茶几、座椅、飲水機、櫃體、盆栽、門片與玻璃隔間具有簡化平面碰撞。碰到障礙會停止該方向，仍可沿邊緣滑行。
- 地板與入口平台限制活動範圍，無法無限走離場景。入口玻璃門改為開啟狀態，留下可通行間隙。
- 互動以各地點前方的站位為中心：入口0.9公尺、櫃檯1.15公尺、候診區0.85公尺、醫師診桌前0.95公尺。還會檢查連線通道，避免隔著牆或家具互動。
- 靠近提示依人物實際位置計算；互動時再次驗證距離。自由行走的櫃檯／候診區勾選在互動後記錄，點擊導航則保留原有抵達紀錄。
- 小地圖位置隨人物連續更新。自由行走時，沒有鄰近地點就不顯示上一個地點為當前位置。

這是單層診所的地面行走與平面碰撞，沒有跳躍、樓層或完整剛體物理。模型的裝飾細節不逐一建立精密碰撞；可通行區與主要家具佔位集中在`freeWalk.ts`，後續改動家具時需同步核對。

## 焦點、相容與清理

方向鍵只在3D畫布取得焦點時控制角色，不攔截產品搜尋或對話頁的輸入。失去畫布焦點、視窗失焦、頁面隱藏、離開場景及WebGL切換時停止或釋放控制；重新拜訪回到入口，不延續舊按鍵。E／Enter不因長按重複觸發互動。

「減少動態效果」設定下，自由行走仍可操作，但不播放交替步態；自動導航快速抵達。WebGL2不可用或內容遺失時，沿用V3的簡易場景，改用地點點擊玩法，原產品及挑戰流程仍可操作。

介面與3D中文字體沿用「微軟正黑體」。Three.js仍採延遲載入，沒有增加外部模型、服務、付費API或雲端資料寫入。

## 驗證紀錄

`npm test`：53項單元測試通過，原46項加7項V4驗證。`npm run build`：TypeScript與靜態建置成功。Three.js引擎區塊約551.6kB（gzip137.7kB），V4場景區塊約39.4kB（gzip15.4kB）；Vite仍有引擎區塊超過500kB的提示，透過延遲載入處理，未隱藏提示。

最終完整瀏覽器回歸：54個案例中53項通過、1項不適用、0項失敗。唯一不適用項目為桌機專案中的「手機雙指縮放」，同一案例在手機專案通過。V4新增的8項桌機／手機自由行走案例全部通過。

正式Google公開CSV已在桌機及手機模擬中完成實際產品搜尋與五題100分挑戰；題幹、四選項與答案對照來源回應。另完成原有點擊探索、答案鎖定、80分不通關、錯題回顧、重玩、匯入、連線重試、照片、3D鏡頭及簡易場景切換回歸。

已在桌機與手機模擬中，實際按方向鍵完成入口→櫃檯E互動→醫師Enter互動→五題100分；測試只讀取實際座標並送出鍵盤事件，未直接指定人物位置。另驗證碰撞、放開即停、反向鍵、鏡頭方向、長按觸控、減少動態、焦點切換、中斷導航後等待舊路線到期，以及重新導航／重新拜訪。
