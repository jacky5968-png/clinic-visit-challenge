## 重跑方式

先啟動本機建置預覽，再執行閱讀性檢查：

```powershell
npm run build
npm run preview -- --port 4173 --strictPort
```

另一個終端機，在專案根目錄執行：

```powershell
node scripts/verify-readability.mjs
node scripts/verify-readability-preservation.mjs
npm test
npm run test:e2e
```

閱讀性檢查預設使用 127.0.0.1:4173，可由 READABILITY_URL 環境變數指定其他本機預覽埠。使用既有正式CSV快照作為瀏覽器測試資料；不回寫來源。即時正式來源另由既有 official.spec.ts 驗證。
