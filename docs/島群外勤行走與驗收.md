# 島群外勤行走與驗收

2026-10-25，延續外勤養成V5七島本機版。未發布、未新增產品照片、未修改原題庫。

## 完成的流程

1. 島群加入沿用原人物模型的外勤，保留公事包、服裝與手腳行走動作，旁有「外勤」標記。
2. 點選已解鎖島名或島體，外勤走島內環形步道，再沿相鄰木橋到目的島。需跨多島時依相連木橋行走，不直穿海面或島上建築。
3. 抵達後顯示該關原限定題庫。選好產品／主題，再進入原3D教室、藥局或診所。
4. 若已選好題庫按「開始第N關」，會等外勤抵達後才呼叫原開始流程；不會重選第一項題庫。已抵達該島時直接進場。
5. 提供「略過移動」及「取消前往」。略過只完成走路，仍保留題庫與挑戰；取消返回出發島，不會偷偷進場。
6. 走路期間暫停換關、換題庫與相機操作，保持全景。離開頁面會停止動畫與回呼。回到島群，外勤仍在剛拜訪的島；這個位置只存在本次頁面記憶體，不新增通關紀錄。
7. 已實作減少動態時直接抵達、3D未就緒時退回原題庫流程。分頁或地圖隱藏時暫停，低更新率下仍按實際時間移動。
8. 新增環島步道、延長並抬高橋端，使人物走在橋面。島名避開人物及標記；320px地圖將長的通關提示縮成「已通關」，清單仍顯示完整提示。字型沿用微軟正黑體。

## 題庫與遊戲保護

原分類限制、逐關解鎖、五題隨機、四選項、送出鎖定、100分通關、80分不解鎖、原診所內自由行走、醫師／藥師氣泡與動畫均保留。走路不抽題、不計分、不完成關卡。

本次驗證時原公開CSV已為91項題庫、1,760題；唯讀下載到 `output/island-walking-live-source.csv` 作核對，未寫回來源，也未更動原測試fixture。原問答專案與產品照片保持不變。

## 驗證結果

- TypeScript／Vite建置成功，118項單元測試通過。
- 對七座島所有前後拜訪組合，驗證桌機／手機路線只用相鄰橋，橋上點在橋中線，目的地為正確入口；鎖定目的地不能產生路線。
- 桌機及390px、320px手機尺寸實際查看橋上人物動作，島名未遮人物、標籤未互相重疊、無頁面橫向溢出。
- 取消立即回島、取消待進場不誤進場、正常抵達、略過抵達、已抵達後進場與返回島群位置保留均已操作。
- 非預設的Ascofen及「肌肉骨骼用藥」題庫未被重設。進入正確場景後，醫師／教官氣泡顯示同一題庫。
- 隔離測試來源 http://localhost:4173/ 沿用先前7/7測試進度，重玩七關、共35題；逐題核對原文與四個選項、五題無重複、送出鎖定，每關100分。未代替平常 http://127.0.0.1:4173/ 的使用者通關；其第二島仍鎖定。
- 181份受保護檔案雜湊相同；Products原分類篩選、選題、題數與CSV載入函式逐段一致。原App、計分、通關、題庫與診所人物／場景程式未改。
- 手機為瀏覽器尺寸模擬，非實體手機/GPU實測。減少動態與GPU失敗退回已實作，未在本次強制模擬環境故障。
