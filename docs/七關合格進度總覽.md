# 七關合格進度總覽

入口位於產品選擇頁的3D島群上方，可收起整個總覽，或展開／收合各關、一次展開全部名單。

每關顯示通關／已開放／待解鎖、已合格數、尚差項數，以及下一關的解鎖條件。展開後列出指定分類內的完整「已合格」「尚未合格」產品／主題與有效題數。每關任選5項合格即可通關，不必考完全部名單；最後一關顯示七關完成條件。

直接選擇已開放且至少有10題的項目，可切換至正確關卡及題庫，再按原本的開始按鈕進入木橋行走、3D交流與10題挑戰。未解鎖關卡只供查看；外勤移動時無法從總覽切換題庫。

總覽只讀取既有 `StageQualifications`，不另存進度、不重新定義合格條件。每項10題全對、每關5項不同產品／主題、版本核對及依序解鎖全部沿用原邏輯。題庫、照片、3D場景、行走路徑與舊紀錄均保留，僅更新本機版，未發布。

桌機展開名單左右並列，手機改為單欄；保留微軟正黑體、文字換行與鍵盤展開操作。

## 產品／主題搜尋與未合格篩選

搜尋欄跨七關比對產品／主題名稱，支援部分名稱、不分英文大小寫，並可處理全形英文及前後空白；畫面仍保留題庫原名。勾選「只看尚未合格」可隱藏已合格項目，也可與名稱搜尋合併使用。

符合條件的關卡會自動展開，顯示符合項數及原名單總數；仍能自行展開／收合。清除篩選會同時清空搜尋與取消未合格篩選，恢復完整名單與原本的展開狀態。找不到結果時會清楚提示，不會誤報所有產品都已合格。

搜尋及篩選只影響名單，不影響各關已合格數、尚差項數、既有解鎖與選題權限。未解鎖項目可以查找，但不能選取；沒有新增進度儲存或修改題庫。
