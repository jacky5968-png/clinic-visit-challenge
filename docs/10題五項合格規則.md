# 10題／每關五項合格規則

每項產品／主題從該項原題庫抽10道不重複的有效題目，每題10分；10題全對100分才合格，90分不合格。不足10題不可開始，不重複抽題湊數、不以其他題庫替代，也不改寫原CSV。

每關累積至少5項不同產品／主題合格才通關並解鎖下一關。前兩關的「新人必修」「商品名測驗」以原題庫內的不同主題計算。七關指定分類、3D場景、木橋行走與對話流程保留。重複挑戰同一項不增加合格數；合格結果可繼續挑戰本關其他項目。

新版紀錄使用 `field-training-seven-stages-v2`，儲存版本2、關卡、完整名稱、題庫內容版本、10題全對的合格題數及日期。舊 `field-training-seven-stages-v1` 與三診所紀錄不刪除、不覆寫，不換算成新版合格數。原題庫內容或分類更新後重新核對，失效的合格項目不計入，但歷史紀錄保留。重新整理後恢復新版進度；儲存不可用時以本次頁面記憶繼續。

規則集中於 `src/config/challenge.ts`。原題庫與產品照片未修改；僅在本機執行，未發布。
