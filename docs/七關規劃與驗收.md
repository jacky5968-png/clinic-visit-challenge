分類以原CSV的「顯示分類」優先，空白時沿用「藥理分類」。複合分類按 `|` 或 `｜` 拆分，精準比對標籤；同一題庫可屬於不同關卡，通關分開計算，因此各關項目數與題數有重疊。

例如「呼吸系統｜自費」可用於第三、四關，「泌尿科｜自費」可用於第四、七關。第二關中名稱為「糖尿病」「呼吸系統」的主題，分類仍為「商品名測驗」，只列於第二關。第七關依分類也包含標有相應慢性病分類的給付規定主題。

來源設定仍在 `src/config/quiz.ts`。原Google題庫與原「互動式問答」程式未改動。讀取核對結果見 `output/seven-stage-feasibility.json`。

## 已確認的遊戲規則

1. 先選關卡，再選該關限定的一項產品或主題。
2. 每次從該項原題庫抽5道不同題目，保留原題幹、四選項與正確答案。
3. 每題20分，五題全對100分才通過該關，依序解鎖下一關。80分可看錯題、重試。
4. 已通過的關卡可重玩。第七關通過後顯示七關完成。
5. 下一關先回到其限定題庫選擇，確認題庫後再開始。
6. 題數不足、分類不符或題庫連線失敗時，不用其他分類或示範題替代。可重試正式來源或手動匯入符合分類的CSV。

## 場景與進度

前兩關以主題訓練呈現，加入教官、訓練白板及教材標籤，主題介面不顯示不適用的成分與產品照片欄位。第四關的主要對象謝藥師實際位於藥局櫃台，使用原藥櫃與陳列；診間不另放一位謝藥師。其餘四關由指定醫師接待。

保留3D行走、相機旋轉／縮放、人物轉向與點頭、人物旁氣泡、返回探索、手機方向控制及WebGL備援。

七關進度使用獨立本機鍵 `field-training-seven-stages-v1`，從第一關開始；舊三診所鍵 `field-training-v5-missions` 原樣保留。通關紀錄按關卡與題庫內容版本核對，不儲存作答明細；來源內容或分類更新後會重新核對，原歷史紀錄保留。無法寫入本機時，仍可在本次頁面完成並解鎖下一關。

## 驗證結果

- TypeScript及Vite本機建置通過。
- 98項單元測試、13個測試檔通過，包含既有92項與新增6項七關規則。
- 新版瀏覽器測試10項通過（1440px桌機、390px觸控手機各5項），無失敗或略過。
- 桌機與手機皆完整走完七關；第一關先答80分確認不解鎖，再重試100分，逐關完成到7／7，重新整理後保留。
- 每一關清單逐項對照原CSV分類；每題題幹、四選項及答案對照所選題庫，確認未跨題庫抽題且五題不重複。
- 每關交流畫面檢查氣泡在場景內，避開人物完整輪廓與地點按鈕；第四關檢查謝藥師及三位人物的正確場景配置。
- 驗證3D行走、旋轉縮放、同場景交流及返回探索、減少動態、WebGL失敗備援、題庫失敗／分類錯誤匯入與本機儲存失敗。
- 保存檢查144個既有檔案與8項結構通過。原抽題／計分引擎、原CSV解析與來源設定、照片、既有動作控制、行走演算法及原題庫專案保持原內容。原題目、選項、作答鎖定與送出介面亦比對一致。

已重新開啟桌機七關選單、手機題庫選擇、教官交流與謝藥師交流截圖。手機為Microsoft Edge尺寸／觸控模擬，未使用實體手機；畫面字型沿用微軟正黑體。
