# 外勤養成V3｜操作與驗收

日期：2026-10-25。版本3.0.0，沿用`clinic-visit-challenge`與本機網址`http://127.0.0.1:5173/`。

V3使用Three.js建立可旋轉、縮放的3D診所，保留正式CSV、產品選擇、櫃檯與候診區互動、醫師對話、五題挑戰及結果頁。此次未發布，未補充產品照片，未修改原「營一大挑戰」專案或Google題庫。

## 操作方式

1. 按「開始遊戲」，選擇產品，再按「開始拜訪」。正式CSV載入狀態與搜尋方式沿用V2。
2. 在診所畫布以滑鼠拖曳或單指拖曳旋轉；滾輪或雙指開合縮放。畫布上方提供左右旋轉、縮小、放大、俯視及重設視角按鈕，旁邊顯示縮放百分比。
3. 點擊3D入口、掛號櫃檯、候診座椅或診桌，以及其上方的地點標籤，均可前往該地點。也可使用場景下方小地圖，不必精準點擊模型。
4. 3D外勤會沿走道行走，手臂、腿部與膝部交替擺動；小地圖位置同步。行走中可旋轉鏡頭，或按「略過移動」立即抵達。
5. 櫃檯與候診區保留選擇性對話，可直接前往醫師。抵達後按「進入診間」，再沿原有對話進入五題挑戰。
6. 每題20分，五題全對、100分才通關。答案鎖定、錯題回顧、重玩、更換產品與返回首頁保持原有方式。

畫布取得鍵盤焦點後，方向鍵旋轉、`+`／`-`縮放、`Home`重設；所有工具列及地點按鈕也可用Tab／Enter操作。縮放限制為65%～225%，垂直角度限制避免翻至地板下方；水平可繞場景旋轉。畫布攔截滾輪與觸控手勢，捲動頁面時可從場景外側操作。

## 3D範圍與相容處理

- 診所為真正的WebGL2場景：立體地板、牆面、窗戶、玻璃隔間、櫃檯、座椅、診桌、盆栽、樹木、醫師及關節外勤。使用程式幾何建模，沒有下載外部模型或新增產品影像。
- 使用OrthographicCamera與OrbitControls；場景物件以Raycaster拾取，地點標籤依世界座標投影到畫面。旋轉與拖曳分開判斷，拖曳不會誤當成拜訪點擊；雙指手勢不觸發地點。
- 沿用V2的路線拓撲並轉換為3D公尺座標，以實際路段長度分配行走時間；目前是地點導航，尚未加入自由行走或碰撞引擎。
- 從後方觀看時牆面降低透明度，方便觀察室內。放大後可用小地圖前往已移出畫面的地點，或按重設視角。
- 首頁場景預覽、醫師對話與答題介面保留既有SVG／HTML，3D升級集中於診所探索。
- WebGL2初始化失敗或顯示內容遺失時，自動切換V2簡易場景。該次探索回到入口，已選產品仍保留，可繼續拜訪與答題。
- 開啟「減少動態效果」會快速抵達目的地、停止步態與鏡頭慣性；使用者仍可主動旋轉、縮放。
- 場景離開時取消動畫與移動計時器，移除監聽器，釋放幾何、材質、貼圖、陰影及WebGL資源。
- 介面與3D招牌文字優先使用「微軟正黑體」。

## 模組與效能

| 檔案 | 用途 |
| --- | --- |
| `src/components/Clinic3DExplorer.tsx` | 3D工具列、投影地點標籤、對話、小地圖與簡易場景切換 |
| `src/three/buildClinic.ts` | 原創診所幾何、家具、光影物件與地點拾取群組 |
| `src/three/person.ts` | 醫師與外勤關節模型、步態 |
| `src/three/createClinicRenderer.ts` | WebGL渲染、鏡頭、觸控、鍵盤、拾取與資源釋放 |
| `src/engine/clinic3d.ts` | 座標轉換、行走路徑取樣與鏡頭限制 |
| `src/hooks/useClinicJourney.ts` | 移動狀態、抵達、略過與計時器清理 |
| `src/styles/clinic3d.css` | 3D場景與桌機／手機版面 |
| `tests/clinic3d.test.ts` | 座標、路徑、縮放與關節姿勢驗證 |
| `tests/e2e/three.spec.ts` | 實際WebGL、鏡頭、拾取、觸控與切換驗證 |
| `scripts/verify_v3_preservation.py` | 唯讀比較V2備份、照片、答題引擎與原專案雜湊 |

3D模組在開始拜訪時才載入，首頁及選品頁不預載Three.js引擎。採像素比上限2、1024陰影貼圖；畫面靜止時不重複繪製，但仍以動畫回呼檢查鏡頭及移動狀態。沒有保證各裝置固定幀率。

正式建置的Three.js獨立區塊約551.6kB（gzip約137.7kB），3D探索模組約30.3kB（gzip約11.9kB）。Vite對引擎區塊超過500kB提出提示；建置成功，採延遲載入，未隱藏此提示。
