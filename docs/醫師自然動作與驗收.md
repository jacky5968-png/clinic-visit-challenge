# 醫師自然動作與驗收

日期：2026-10-25。僅更新本機版，未發布。預覽：http://127.0.0.1:4173/。

## 動作與操作

- 外勤進入原本的醫師互動範圍時，醫師會以頭部與上半身平順轉向外勤，並簡短點頭致意。外勤在附近移動，醫師會跟隨外勤位置調整朝向。
- 醫師維持坐姿，座位、角色根節點、雙腿與膝蓋不移動；上半身與頭部轉動設有限制。
- 原有三段交流中，醫師說話時會短暫點頭、微微前傾與做小幅手勢；聆聽外勤回覆時以較輕的點頭回應。
- 每一段對話只觸發一次約1.4秒的動作，接著平順回復。停留時不會一直重播，重新進入交流可再次觸發。
- 外勤離開醫師附近後，醫師上半身與頭部回復原始姿勢。
- 減少動態效果模式直接調整朝向，關閉點頭、前傾及手部動態；原文字與操作仍可使用。
- 沿用既有互動範圍、遮擋判斷與人物旁氣泡。返回探索及三段交流後的五題挑戰流程不變。對話字型仍為微軟正黑體。
