# 七島自由探索改版與驗收

日期：2026-10-26。現行規則見 [遊戲規則](遊戲規則.md)。

## 改版結果

- 七關從開始就可自由進入，移除前關成績與產品合格數的進入限制。
- 點島嶼或關卡清單先開啟任務說明；按「選擇本關題庫」才顯示產品／主題。取消或 Esc 返回地圖，不開始行走或抽題。
- 移除地圖右側任務資訊卡，七島改全幅顯示。總覽保持預設收合，保留搜尋與尚未合格篩選。
- 合格以單一產品／主題10題全對、100分記錄。各關至少一項合格時顯示已有合格紀錄，僅供學習追蹤，不作為進入任何關卡的條件。
- 保留場景內01→02→03交流、自動行走、三段考核交流、抽題、鎖定答案、錯題回顧與重試。
- 首頁加入可旋轉的真3D雙人訓練基地；首頁、地圖、卡片、場景、題目、成績統一立體邊框、光影及按壓回饋。微軟正黑體沿用，沒有新增產品照片。

## 實際驗證

CUA操作本機瀏覽器，沒有在公開站進行作答。

- 1440×1000、390×844、768×1024、1024×768各驗證七關；320×740再檢查三個代表關卡，共31組任務說明／題庫檢查。所有島標示可操作，沒有橫向溢出、標示互撞或遮住建築／外勤；右側任務資訊卡數量為0。
- 所有案例確認點島時題庫仍隱藏，按說明中的確認按鈕後才開啟題庫；完整核對分頁名稱及分類。
- 沒有任何合格紀錄時直接開始第七關，選擇非預設產品Dalisoon；走過原交流流程、隨機10題均與原CSV的題幹／四選項一致，100分留下第七關獨立合格紀錄。重新整理後紀錄仍保留，其他島都可進入。
- 新訓中心相關法規刻意答錯一題，10題不重複，90分不留下合格紀錄。
- 390×844、768×1024、1024×768測驗頁均無橫向溢出，四選項完整、按鈕高度超過44px，3D雙人考核場景正常。手機成績頁按鈕文字完整。
- 總覽搜尋Dalisoon顯示1項；勾選「只看尚未合格」後變0項；清除篩選可恢復。關卡清單與Esc取消說明後返回原關卡焦點，題庫保持關閉。
- 大樓巡覽回歸：平板視窗標語「誠正精新、造福人群」完整、安全取景、關閉後返回七島。
- 新版遊戲說明六步驟於320px寬視窗完整呈現、沒有橫向溢出，Esc可關閉。
- npm test：24個測試檔、182個測試通過。npm run build：TypeScript及正式建置通過。既有Three.js共用chunk大小警告不阻擋建置。

畫面採瀏覽器尺寸模擬，並非實體手機或iPad Safari測試。瀏覽器回歸腳本已更新於tests/stages-e2e/journey.spec.ts；本輪實際UI驗證使用CUA，未另以終端執行Playwright套件。

## 效能處理

首頁3D重用既有低多邊形模型，動態載入，像素比最高1.5，靜態陰影快取；僅在視角或尺寸改變時繪製。實測首頁長時間閒置，繪製計數維持5→5，沒有持續繪圖。沒有加入高精度外部模型、影片或額外後製。此驗證沒有宣稱實體裝置FPS。
