# 遊戲規則｜七島自由探索版

1. 七座島嶼全數開放，玩家可從任何關卡開始。
2. 點島先看關卡說明；按「選擇本關題庫」後，再選一項產品／主題。
3. 各關僅顯示原題庫的指定分類。題目、四個選項與正確答案不改寫；有效題數少於10題的項目不能開始。
4. 按開始後外勤沿木橋抵達場景。依01→02→03完成交流；01、02完成對話會自動前往下一站，03三段交流後進入考核。
5. 每次抽10題，每題10分。選答案後確認送出即鎖定。10題全對100分才算本項合格，90分仍未合格。
6. 結果頁可回顧錯題、再挑戰、選其他產品或探索其他島嶼。每項合格獨立記錄，不以產品數量限制關卡進入。
7. 合格進度總覽預設收合，可搜尋產品／主題並只看尚未合格；篩選不改變實際紀錄。
8. 紀錄保存在目前瀏覽器，依原題庫版本重新核對；舊紀錄保留。換裝置、網址來源或清除網站資料不會同步。
9. 方向鍵／WASD或手機方向按鈕行走，點地點可自動前往。抵達人物定位點會自動對話，E／Enter可再次互動。拖曳旋轉，滾輪／雙指縮放。
10. 製劑大樓可點選放大巡覽。X、Esc或「回到七島全景」均可關閉；縮放會保留屋頂標語的完整範圍。

關卡與角色為訓練情境，題庫來自「營一大挑戰」。本版不儲存逐題作答明細、個人身分或上傳成績。正式題庫連線失敗時可重試或匯入CSV；不支援3D時仍可使用清單及簡易場景。
