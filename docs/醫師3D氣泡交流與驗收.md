# 醫師3D氣泡交流與驗收

日期：2026-10-25。維持本機版，未發布。預覽：http://127.0.0.1:4173/。

## 操作與行為

- 外勤靠近醫師後，按 E、Enter 或「進入診間」，即可直接在現有 3D 診所交流。
- 原有三段對話保留：各診所醫師的問候、外勤原有回覆、各醫師的挑戰邀請。共用 `src/data/doctorConversation.ts`，沒有新增醫藥內容。
- 氣泡依序連到醫師、外勤、醫師，顯示本次產品及 1／3～3／3 進度。原照片留在任務產品欄，沒有新增產品照片。
- 交流期間保留同一個畫布、外勤位置及視角；暫停行走與地點導航，仍可旋轉、縮放、俯視。
- 氣泡右上角的 × 可返回探索，再次與醫師交流時從第一段開始；原本抽出的五題不重抽。
- 第三段才會顯示「接受醫師挑戰」，接入原有五題、每題20分、全對100分通關流程。
- 氣泡避開四位人物完整輪廓，地點標籤重新排開；連線位於地點標籤與外勤標記後方。手機保留較高的對話空間，長文字可在氣泡內捲動。
- 字型沿用微軟正黑體，對話18px，主要按鈕至少44px。沒有 WebGL 或顯示內容遺失時，沿用簡易場景及原診間對話備援。

## 已完成驗證

- 84 項單元測試、11 個測試檔通過，包含三間診所原對話，以及返回探索不改變五題內容或其他畫面狀態。
- 6 組專項通過：1440、768、390、320px，另有390px減少動態與無WebGL備援。
- 專項檢查同一個畫布與人物位置、視角保留，交流時按行走鍵／E／Enter不會移動或跳過對話；返回探索後仍能再進入。
- 三段氣泡皆檢查人物輪廓、地點按鈕與場景邊界，無水平溢出；檢查旋轉、俯視、返回探索與再進入後定位。
- 桌機、手機及備援模式均完成五題100分挑戰，其他尺寸也檢查可正常進入題目。
- 保存檢查通過：139個既有檔案及8項結構／原規則比對。新增返回探索動作以外，原有狀態處理、抽題、作答與計分程式逐字相同；診所模型僅額外回傳既有醫師關節，幾何未改。
- 完整回歸合併診所任務重跑：61項通過、1項桌機不適用的雙指縮放測試略過。正式CSV、80／100分、重玩、跨診所進度與照片驗證均通過。
- TypeScript 與 Vite 本機建置成功。完整遊戲回歸及更新介面身分檢查後的診所任務重跑結果，分別見 `output/doctor-scene-regression.json`、`output/doctor-scene-missions-regression.json`；合併結果由摘要檔列出。

手機測試使用Microsoft Edge尺寸與觸控模擬，未使用實體手機。已重新開啟桌機邀請、390px醫師問候及320px外勤回覆截圖，檢查文字與人物可見性。
