# 藥師、掛號人員動畫與寒暄對話驗收

更新日期：2026-10-25。僅更新本機版，預覽網址：http://127.0.0.1:4173/。未發布。

## 操作與行為

- 外勤靠近藥局或掛號櫃台時，對應人員轉向外勤，短暫招手；移動時會持續調整朝向。離開後回復原朝向。
- 點選人員自動走近，或方向鍵／手機方向按鈕走近後按 E、Enter 或對話按鈕，會開啟簡短寒暄並點頭回應。
- 藥師與掛號人員各有三組問候與外勤回覆，包含「早安」「今天有什麼事」「怎麼那麼久沒來」。點「繼續聊聊」可輪替對話。
- 招手與點頭會在約 1.8／1.6 秒內結束，避免原地不停擺動。減少動態效果模式直接調整朝向、停止手臂及頭部動畫，仍可對話。
- 原任務文字保留在「拜訪提醒」內，點擊即可展開。不新增完成寒暄的通關條件。
- 簡易場景沿用同一組寒暄；無 WebGL 時仍可完成拜訪及挑戰。
- 對話採微軟正黑體、18px 內文與實色底，文字出現時不使用透明淡入，維持閱讀對比。

## 驗證方式

- `npx vitest run --maxWorkers=1`：遊戲邏輯、場景幾何與新增角色動畫測試。
- `npm run build`：TypeScript 與本機靜態建置。
- `PLAYWRIGHT_PREVIEW=1` 環境下執行既有 Playwright 測試：桌機與手機完整遊戲回歸。
- `node scripts/verify-staff-animation.mjs`：1440px、390px、320px；減少動態與 WebGL 失敗模式；人員點選、問候輪替、E／Enter、提醒展開、無水平溢出與瀏覽器錯誤。1440px／390px 另外以真實方向鍵測試手動靠近時先招手、尚未互動不自動開對話、停止後不反覆招手。
- `node scripts/verify-person-neutral-geometry.mjs`：外勤、醫師與兩位人員的靜止／步行模型，與修改前備份逐一比對。
- `node scripts/verify-staff-animation-preservation.mjs`：對照本次備份與原題庫來源程式 SHA-256。

已通過：76 項單元測試、12 組新增互動驗證、61 項完整遊戲瀏覽器測試；另 1 項桌機雙指縮放測試依既有設定略過。人物原始外觀與步態另有 8 組幾何比對通過。
