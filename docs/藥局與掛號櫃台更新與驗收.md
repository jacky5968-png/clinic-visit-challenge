# 藥局與掛號櫃台更新與驗收
日期：2026-10-25；版本：外勤養成V5；僅更新本機版，未發布。

## 區域與擺設

| 原區域 | 新區域 | 實際擺設 |
| --- | --- | --- |
| 掛號櫃台 | 藥局 | 領藥檯、多層藥櫃、21個無品牌藥盒、5個藥瓶、電腦、備藥包裝 |
| 候診區 | 掛號櫃台 | 移除候診椅與茶几，改為服務檯、掛號電腦、健保卡讀卡機、收據設備與號碼顯示器 |

三間診所套用相同區域配置，各自保留原有主題色。首頁插畫、WebGL無法使用時的簡易場景、小地圖標籤、互動按鈕、說明與任務提示均同步更新。

藥盒與藥瓶為程式建立的無品牌擺設，沒有新增產品照片或藥品知識。中文字體沿用微軟正黑體。

## 遊戲流程與保存

- 保留原地點識別、互動落點、任務條件與拜訪完成紀錄；顯示名稱與情境文字改為藥局確認／掛號報到。
- 保留原題庫、產品資料、讀取設定、每次五題、每題20分、100分通關、重玩及錯題回顧。
- 新家具的碰撞範圍與模型一致；移除舊候診椅的碰撞範圍，避免空地仍擋路。
- 修改前備份：backups/v5-before-pharmacy-registration-20261025.zip，128個檔案，已重新解壓逐檔比對。

## 驗收

- 建置成功；71項單元檢查通過，含三間診所的實際模型、藥盒／藥瓶數量、掛號設備與碰撞範圍。
- 320、390、768、1440px共100項閱讀性與畫面狀態檢查通過，標籤不重疊、未裁切，且不擋住場景物件的點擊位置。
- 桌機與手機模擬均實際點擊藥局／掛號櫃台的3D物件，再以E鍵與互動按鈕確認對話，4個服務點案例全部通過。
- 111個既有檔案與原專案題庫檔案雜湊比對，以及5項導航／任務結構檢查全部通過。
- 62項瀏覽器案例完成驗證：61通過、1略過（桌機不執行手機雙指案例）。鏡頭測試原固定座標會落在新浮動標籤上，已改為從實際露出的畫布拖曳，桌機／手機兩案重測皆通過。
- 手機採Edge觸控模擬；未進行實體手機或Safari驗證。

## 證據與重跑

- 桌機／手機場景：output/playwright/service-points-desktop.png、service-points-mobile.png。
- 首頁插畫：output/playwright/service-points-home-desktop.png、service-points-home-mobile.png。
- 靠近互動與對話：output/playwright/service-points-reception-*.png、service-points-waiting-*.png。
- 檢查結果：output/clinic-service-points-audit.json、output/clinic-layout-preservation-audit.json、output/readability-audit.json。

先執行建置與本機預覽，再於另一個終端機重跑：

```powershell
npm run build
npm run preview -- --port 4173 --strictPort
```

```powershell
npm test
node scripts/verify-clinic-service-points.mjs
node scripts/verify-clinic-layout-preservation.mjs
node scripts/verify-readability.mjs
npm run test:e2e
```

本次保存檢查請使用 verify-clinic-layout-preservation.mjs；先前閱讀性專用的保存腳本記錄的是當時允許變更的範圍。簡易場景插畫可用 generate_assets.py --clinic-only 單獨重建，不會重建其他素材。
