# 營一外勤養成｜八島自由探索版

八座3D島嶼全部開放。玩家自行選擇學習目標：點島先看任務說明，再按「選擇本關題庫」挑選產品／主題，進入場景交流與10題考核。

正式遊戲：https://jacky5968-png.github.io/clinic-visit-challenge/

## 現行遊戲規則

1. 八關自由選擇，沒有前一關成績或產品合格數門檻。
2. 點島嶼或關卡清單只開啟說明，不會開始行走、抽題或考核。確認「選擇本關題庫」後才顯示該關卡的產品／主題。
3. 各關使用指定分類的原題庫；選好一項有效題數至少10題的產品／主題，再按「開始第N關」。外勤沿木橋抵達場景，可略過移動或取消。
4. 場景內仍按01→02→03交流。完成01、02的回應與對話後，外勤自動走到下一站。03完成三段交流後接受考核。
5. 每次隨機抽10題，每題10分，全部答對100分才記為本項合格。90分不合格。答案送出後鎖定，可在結果頁複習錯題並重試。
6. 各產品／主題獨立記錄合格，重複合格不重複計數。可隨時挑戰其他產品或任何島嶼。
7. 「八關合格進度總覽」預設收合，保留名稱搜尋與「只看尚未合格」篩選。紀錄用途為個人學習追蹤，不限制選關。
8. 合格紀錄僅存在目前瀏覽器，按題庫內容版本核對。原歷史紀錄與儲存鍵保留；換裝置、網址來源或清除網站資料不會同步紀錄。不儲存逐題作答明細或個人身分。

詳細規則見 [遊戲規則](docs/遊戲規則.md)。舊開發驗收文件屬歷程，與現行選關規則不同時，以本文件及遊戲內說明為準。

| 06 骨科診所 | 李醫師 | 肌肉骨骼 |

不以其他分類或示範題替代正式題庫。2026-10-26本機快照核對為91項題庫、1760題；實際名單以正式CSV當次讀取結果為準。

八關可選項數依序為8、10、9、9、10、7、17、17；複合分類可在對應關卡重複出現。原題庫「呼吸系統」對應第三關的呼吸系統用藥，不改寫來源分類。

原家醫科的泌尿科／痛風合格紀錄，在原產品與題目內容核對有效後顯示於新內科；糖尿病／高血壓／高血脂紀錄留在第八關。原始儲存紀錄及鍵名保留，重複合格仍只計一次。

## 操作

- 桌機：方向鍵／WASD移動，E／Enter互動；Alt＋方向鍵調整視角，+／-縮放，Home重設。
- 手機／iPad：長按方向按鈕或點地點自動前往，拖曳旋轉、雙指縮放。從場景外側捲動頁面。
- 點選生達製劑大樓可放大巡覽；屋頂標語維持置中，縮放與旋轉會依標語範圍調整安全取景。X、Esc或返回按鈕關閉後回到八島全景。
- 不支援WebGL時保留簡易場景與清單，仍可選關、交流及答題。支援系統「減少動態效果」。

## 本機啟動與建置

使用Node.js 22.12+、24或26以上支援版本。可雙擊「啟動遊戲.cmd」，或執行：

```powershell
npm ci
npm run dev -- --port 5173
npm test
npm run build
npm run preview -- --port 4173
```

開發伺服器預設僅綁定127.0.0.1。GitHub main分支推送後會由Actions執行測試、建置與Pages部署。發布說明見 [GitHub發布說明](docs/GitHub發布說明.md)。

## 題庫讀取與格式

啟動時唯讀載入src/config/quiz.ts的正式公開CSV。可重新讀取，或在題庫頁匯入UTF-8 CSV。本版未修改原Google Sheets、原CSV、來源分享權限或原問答專案。

| 用途 | 英文欄名 | 中文欄名 |
| --- | --- | --- |
| 產品 | product | 產品、產品名稱、商品名稱 |
| 題目 | question | 題目、問題 |
| 四選項 | optionA～optionD | 選項A～D、選項 A～D、A～D |
| 答案 | answer | 正確答案、答案 |
| 分類 | category | 顯示分類優先，其次藥理分類 |
| 成分／圖片（選填） | ingredient／image | 成分／產品圖片 |
| 解析／審核（選填） | explanation／explanationReviewed | 解析／解析已審核 |

答案接受A～D、1～4或與唯一選項完全一致的文字。CSV可含BOM，支援引號內逗號及換行。缺欄、選項重複或答案無效的列會略過並提示，同產品同題幹去重。只有審核標記成立的原始解析才顯示；未提供內容不自行補寫。每項至少需10道有效題目。

VITE_QUIZ_CSV_URL可覆寫公開來源；所有VITE_設定會進入前端，不可放入私人憑證。手動匯入僅影響本次瀏覽，重新整理後恢復正式來源。

## 設計與效能

首頁恢復原有診所全景，含藥局、掛號櫃台、醫師診間與外勤代表，可拖曳旋轉。重用既有診所模型，以最高2倍像素比、2048靜態陰影及文字貼圖異向性過濾提高畫質；總繪製像素控制在240萬以內，只在視角或尺寸改變時繪製。無WebGL時沿用原SVG診所圖。八島全幅呈現，任務說明改為點選彈窗。主介面、題庫卡、測驗、結果頁統一使用立體邊框、光影與按壓回饋；不增加大型影片、後製或外部高精度模型。中文字體優先微軟正黑體，未新增產品照片。
